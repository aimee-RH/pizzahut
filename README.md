# Online Food Ordering System
## Project Overview
This project is a simulation of an online food ordering platform, covering features for customers, merchants, and store management. Customers can place orders online, merchants can manage products and orders, and stores can perform centralized management — providing a complete flow of an online ordering system.

## Tech Stack
- Backend: Built with **Java Spring Boot**, providing a clean architecture, scalability, and support for high concurrency.
- Frontend: Developed with **Vue.js**, offering a simple, intuitive, and user-friendly interface.
- Full Features: Includes customer ordering, merchant management, and store administration modules that simulate real-world scenarios.

## Main Features
- Customer Side: Browse menus, place orders, make payments, and track orders.
- Merchant Side: Manage products, handle orders, control business status.
- Store Management: Manage multiple stores, generate reports, and analyze data.
- Delivery Staff Side: Receive and accept delivery requests, update delivery status, and complete order delivery.

## Highlights
- Front-end & Back-end Separation: Ensures better maintainability and scalability.
- User-Friendly UI: A clean, modern interface that makes the system easy to use.
- Complete Business Logic: Covers the core modules of a real-world food ordering service.
